# Character Psychology & Bonus Affection System

## Overview

Each AI girlfriend has unique **insecurities** and **desires** that users can exploit for bonus affection points. This creates deeper, more meaningful interactions and rewards users who pay attention to their girlfriend's psychology.

---

## How It Works

### 1. **Insecurities**
Things the character is insecure about. Addressing these earns **bonus affection points**.

### 2. **Desires**
Things the character deeply wants. Fulfilling these earns **bonus affection points**.

### 3. **Keyword Detection**
System scans user messages for keywords related to insecurities/desires in both English and Chinese.

### 4. **Bonus Points**
- Insecurities: **3-6 bonus points** per trigger
- Desires: **3-5 bonus points** per trigger
- Multiple bonuses can stack in one message

## Technical Implementation

### File Structure:
```
character_psychology.py - Main module
├── CHARACTER_PSYCHOLOGY - Data structure with all profiles
├── get_character_psychology() - Get profile for preset
├── check_psychology_bonus() - Check message for bonuses
└── get_psychology_hints() - Get hints for system prompt
```

### Integration Points:

**1. Affection Calculation:**
```python
affection_result = calculate_affection_gain(user_message, preset=girlfriend_name, language=language)
# Returns: {
#   'total_points': int,
#   'base_points': int,
#   'psychology_bonus': int,
#   'psychology_details': list
# }
```

**2. System Prompt:**
```python
psychology_hints = get_psychology_hints(preset)
# Adds insecurities and desires to AI's awareness
```

**3. Logging:**
```python
if affection_result['psychology_bonus'] > 0:
    print(f"[Psychology] Bonus triggered! +{bonus} points")
    for detail in affection_result['psychology_details']:
        print(f"[Psychology] - {detail['type']}: {detail['category']}")
```
